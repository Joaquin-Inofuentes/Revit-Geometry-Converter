# _Revit_EXE_Geometrias
- **IN (Entrada):** Archivos de modelo de Revit (`.rvt`) y su geometría extraída en formato binario TBT2 (`export.bin`), además de parámetros de decimación.
- **OUT (Salida):** Mallas 3D optimizadas (`export.obj`, `export_optimizado.glb`, `export.tbv`), reporte de decimación y una vista web interactiva para visualización.
- **Intención:** Extraer, simplificar y optimizar la geometría 3D de modelos de Revit a formatos ligeros para su visualización web eficiente mediante decimación QEM.

## Documentación Automática
Se han generado reportes y diagramas mediante el Analizador. Puedes consultarlos en la carpeta `_Documentos generados`.
